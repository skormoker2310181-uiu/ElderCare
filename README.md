# ElderCare

An accessibility-focused mobile application prototype designed to support older adults through an intuitive and user-friendly interface.

## Overview

ElderCare is an individual Human–Computer Interaction (HCI) project that applies Human-Centered Design principles to create an accessible mobile experience for older adults. The prototype emphasizes simplicity, readability, and essential healthcare features that promote independence and improve usability.

## Objectives

- Improve accessibility for older adults
- Simplify everyday health management
- Design an intuitive mobile interface
- Apply Human-Centered Design principles

## Features

- Medication Reminder
- Emergency SOS
- Health Dashboard
- Appointment Management
- User Profile
- Accessibility Settings
